# Оценка результатов А/В-теста изменения ленты объявлений

## Описание проекта
- **Бизнес импакт**: 
<br>Увеличение прибыли
- **Продуктовая гипотеза**:
<br>Размещение 4 платных элементов над 1 органическим увеличит Paid CTR на 6.4%, так как пользователи кликают первое, что видят, не пролистывая.
- **Метрики**: 
<br>Paid CTR, Organic CTR, Revenue, Pages Viewed
- **Описание**: 
<br>Данные были получены из теста, проведенного на платформе Marketpele Feed, которая помогает издательствам зарабатывать на рекламе. Список объявлений Marketpele содержит "органические" и "платные" элементы. Платные элементы - это рекламные объявления, при нажатии на них пользователи переходят на страницу рекламодателя и приносят доход Marketpele. Органические элементы - это контент издателя, при нажатии на них пользователи переходят на другую статью от того же издателя.
В упомянутом выше тесте у группы A была лента, составленная из "органического" элемента наверху списка, и с четырьмя "платными" элементами внизу списка.
У группы B была лента с четырьмя "платными" элементами наверху списка, за ними следовал один "органический" элемент.

## Результаты
<br>Рост Paid CTR на 15.8% (p < 0.001) сопровождается падением Organic CTR на 24.7% (p < 0.001), при этом Revenue не изменился (p = 0.985). **Изменение не рекомендуется к внедрению**, поскольку рост целевой метрики сопровождается негативным эффектом по дополнительным метрикам и не приводит к росту дохода.
